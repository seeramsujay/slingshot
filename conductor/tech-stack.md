# DustVision Tech Stack

## Core Language
- **Python 3.10+**: Data processing, ML, and orchestration.

## Data Processing
- **Pandas**: Time-series manipulation and resampling.
- **NumPy**: Numerical computations and vectorization.
- **LanceDB**: Vectorized storage for event lookups and historical analysis.

## Machine Learning
- **Scikit-learn**: Random Forest Regressor for PM forecasting.
- **TensorFlow/Keras**: (Optional) LSTM for complex sequence modeling.

## API & Backend
- **FastAPI**: Asynchronous web framework for microservices.
- **Uvicorn**: ASGI server.
- **Pydantic**: Data validation and settings management.

## Visualization
- **Matplotlib/Seaborn**: Static reports and simulation plots.

## Development Tools
- **uv**: Fast package management and venv control.
- **Pytest**: Unit testing and integration validation.
